# ECLSS Flight Deck Design System

This folder is the design reference for the ECLSS Flight Deck interface. The integrated guide is the working source for future UI changes. The two source addenda preserve the supplied material and explain the detailed constraints behind the system.

## Documents

- [Integrated design system](./design-system.md) — tokens, visual rules, component patterns, and inspection drawer behavior.
- [Anti-slop avionics principles](./anti-ai-slop-avionics-design-system.md) — supplied visual and engineering guardrails.
- [Inspection drawer specification](./inspection-drawer-specification.md) — supplied drawer behavior, content, and layout detail.

## Scope

The current application is a React Native for Windows prototype. Browser-only implementation details in the source addenda (such as HTML range inputs and CSS `backdrop-filter`) are interpreted as visual/product constraints; use platform-appropriate React Native controls and styles. Sample readings and qualification copy remain illustrative unless backed by project data.
